# Commands

One line per command, used by `/guide`. Keep this list in sync with the skills: when a skill is added, renamed or removed, update it here.

| Command | What it is for | Good moment to use it |
|---|---|---|
| `/setup` | Builds or updates the athlete profile: units, FTP, races with A/B/C priority, availability, equipment, other sports, preferences. | First time, or when FTP, weight, a race or the schedule changes. |
| `/plan-week` | Plans the week around availability, fatigue and races, with watts, HR and RPE. Can write it to Intervals.icu after confirmation. | Start of the week, or when the week falls apart. |
| `/today` | Shows today's planned session as planned, with execution notes and fueling. Changes it only when there is a reason. | Before training. |
| `/analyze` | Analyzes a finished ride or day, compares it with the plan and decides the next session. | After training. |
| `/time-off` | Registers, changes or closes a period off the bike (travel, break, no bike, injury, illness) and plans the return. | When you leave the bike, and when you are back. |
| `/fueling` | Fueling and hydration plan for a long ride or race: carbs per hour, bottles, sodium, what to carry. | Before a long ride, sportive or race. |
| `/review` | Reviews a month, block or season: load, compliance, best efforts, durability, progress towards the A race. | End of the month or block. |
| `/guide` | Lists what the coach can do and suggests where to start. | Any time. |
